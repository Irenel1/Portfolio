## AI-Agen for code migration

**Client / Industry:** Profesional services, management platform (NDA)
**Duration:** 1 month
**Team size:** 2 (1 Data Science Lead, 1 Data Science Engineer), collaborating with the implementation team's Business Analyst and Tech Lead on validation

### POC for code rewrite 
A legacy product needed migration from JSP to JavaScript. Rather than a manual rewrite, it was decided to buid AI agent  to accelerate the migration,  to save time and cost impact while maintaining quality.

### My role as PM
I coordinated development and validation of the AI agent used to accelerate the rewrite, collaborated with the implementation team's BA and Tech Lead on validation — running iterative test examples and refining the agent based on their feedback — calculated time and cost savings from AI-assisted rewriting versus manual migration, and reported validation results and savings to stakeholders.

### Competencies 
- **Cost-benefit analysis:** quantified time and cost impact of AI-assisted rewriting against manual migration as the basis for the recommendation
- **Quality management / validation:** ran iterative test cycles against the AI agent's output and refined it against implementation-team feedback before sign-off
- **Stakeholder communications:** reported validation results and cost/time findings to stakeholders to support a go/no-go decision on the approach
- **Cross-functional coordination:** aligned a data science delivery track with the implementation team's BA and Tech Lead on acceptance criteria for the rewrite

### Tools used
- Project & task tracking: Asana
- Documentation: SharePoint

### Technologies the team worked with
JSP, JavaScript

### Outcomes
Reported time and cost savings from AI-assisted rewriting versus manual migration to stakeholders. 

### Challenges
Define scope for the POC, access artifacts,  bring right people to evaluate corectness, usablity of of produced code
